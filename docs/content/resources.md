# Resources

## Course

**[Learn Clean Architecture](https://academy.nimblepros.com/p/learn-clean-architecture)** at NimblePros Academy, taught by [Sarah "sadukie" Dutkiewicz](https://blog.nimblepros.com/authors/sadukie/) and [Steve "ardalis" Smith](https://blog.nimblepros.com/authors/ardalis/). It covers Clean Architecture and how to apply it with this template. Use code **ARDALIS** to save 20%.

Also from NimblePros Academy: **[Documenting Decisions: A Practical Guide to Architecture Decision Records](https://academy.nimblepros.com/p/documenting-decisions-a-practical-guide-to-architecture-decision-records)**.

For team training or implementation help with Clean Architecture or DDD, contact [NimblePros](https://nimblepros.com/).

## Book

**[Clean Architecture with .NET](https://www.amazon.com/dp/1805128531)** by Casey Crouse, with Steve "ardalis" Smith as contributing author (Packt, 2026): *Design scalable .NET applications by using Clean Architecture principles and proven patterns.*
